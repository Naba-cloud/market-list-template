# Market List Template

A web application demonstrating client-side data persistence using **IndexedDB** and **Dexie.js**.

The project explores how browser-based databases can store and manage application data locally, reducing reliance on server-side storage for client-side workflows.

## Key Concepts

- **IndexedDB:** Browser-based storage for structured data.
- **Dexie.js:** A wrapper around IndexedDB that simplifies database operations.
- **Client-side Persistence:** Store data locally in the browser.
- **Data Management:** Work with locally stored application data.

## Tech Stack

- JavaScript
- IndexedDB
- Dexie.js
- HTML / CSS

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Naba-cloud/market-list-template.git
```

### Navigate to the project

```bash
cd market-list-template
```

### Install dependencies

```bash
npm install
```

### Start the application

Use the development command configured in `package.json`.

## What This Project Demonstrates

- Working with browser storage APIs.
- Managing structured client-side data.
- Using Dexie.js to simplify IndexedDB interactions.
- Understanding local data persistence in web applications.
